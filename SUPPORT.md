# Getting help with NOOP

- **🐞 Bugs → open a [GitHub issue](https://github.com/Dhanunjay-Divi/Noop/issues/new/choose).** Include your **NOOP version**, **platform** and **strap model**, plus a **strap log**. NOOP does not collect diagnostics automatically, so without a user-shared log we usually cannot distinguish a protocol fault from setup. (Android: **Settings → Strap → "Share strap log (for bug reports)"**; macOS: the **Live** screen → **Strap log** card → **Copy**/**Save…**.) Never post API tokens, raw databases, or unredacted health exports.
- **💬 Questions and ideas → [GitHub Discussions](https://github.com/Dhanunjay-Divi/Noop/discussions).**
- **👥 Community → [r/NoopBand](https://www.reddit.com/r/NoopBand/)** and the [NOOP Discord](https://discord.com/invite/wKgyqVdjrP).
- **📖 Docs → the [README](README.md)** covers install (macOS Gatekeeper / Android Play Protect), pairing a WHOOP 5.0/MG, privacy, and importing your history.

NOOP is an independent, unofficial project — **not affiliated with WHOOP, Inc.** — and **not a medical device**.
